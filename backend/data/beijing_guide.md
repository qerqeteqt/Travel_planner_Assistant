# 2026 北京深度游玩全攻略

## 1. 目的地简介
北京是中国的首都，拥有三千多年建城史和八百多年建都史，是全球拥有世界遗产数量最多的城市。故宫、天坛、长城、颐和园等皇家建筑群气势恢宏，胡同四合院和京味美食承载着浓厚的老北京烟火气。春秋两季（4-5月、9-10月）是最佳旅行季节，天气舒适，景色优美。北京地铁网络发达，几乎覆盖所有主要景点，出行便捷。

## 2. 核心景点推荐 (含门票与位置信息)

### 2.1 故宫博物院
* **位置**：东城区景山前街4号
* **门票**：60元（珍宝馆+10元、钟表馆+10元）
* **游玩时长**：3-4小时
* **简介**：世界最大规模的木结构宫殿建筑群，明清两代皇家宫殿。需提前7天在官方公众号抢票（每晚20:00放票）。建议走中轴线：午门→太和殿→乾清宫→御花园→神武门。

### 2.2 天安门广场
* **位置**：东城区长安街
* **门票**：免费（需提前7天在"天安门广场预约参观"公众号预约）
* **游玩时长**：1-2小时
* **简介**：世界上最大的城市中心广场，每天清晨的升旗仪式庄严肃穆。周边有人民大会堂、国家博物馆（免费）、毛主席纪念堂等重要建筑。

### 2.3 八达岭长城
* **位置**：延庆区G6京藏高速出京方向
* **门票**：40元
* **游玩时长**：3-4小时
* **简介**：明长城中最具代表性的一段，素有"不到长城非好汉"之说。北八楼好汉坡为最高点。可乘S2线市郊铁路或景区直通车前往，建议早上出发避开人潮。

### 2.4 颐和园
* **位置**：海淀区新建宫门路19号
* **门票**：30元（联票含佛香阁+苏州街60元）
* **游玩时长**：3-4小时
* **简介**：中国现存最大的皇家园林，集北方皇家园林与江南水乡风格于一体。推荐路线：北宫门进→佛香阁→长廊→昆明湖→十七孔桥。佛香阁俯瞰全园视角最佳。

### 2.5 天坛公园
* **位置**：东城区天坛内东里7号
* **门票**：28-35元联票（含祈年殿+回音壁+圜丘）
* **游玩时长**：1.5-2小时
* **简介**：明清两代皇帝祭天的场所，祈年殿为北京城市标志性建筑之一。建议南门进入，清晨可看到大爷们晨练打太极的市井画面。

### 2.6 雍和宫
* **位置**：东城区雍和宫大街12号
* **门票**：25元（含香）
* **游玩时长**：1-1.5小时
* **简介**：北京最大的藏传佛教寺院，原为雍正皇帝府邸。香灰琉璃手串是热门祈福物品。秋季银杏大道金黄满地，景色绝美。

## 3. 特色餐饮与预算参考

* **北京烤鸭**：全聚德（挂炉烤鸭，人均200元）、四季民福（酥不腻烤鸭，人均150元）、便宜坊（焖炉烤鸭，人均100元）。推荐四季民福故宫店，可边吃烤鸭边看故宫角楼。
* **炸酱面**：方砖厂69号、海碗居，八种菜码配浓郁酱香，人均约40元。
* **涮羊肉**：南门涮肉、聚宝源，手切羊肉配麻酱蘸料，人均约100元。
* **炒肝+包子**：姚记炒肝（鼓楼店，60年老字号），人均约35元。
* **卤煮火烧**：门框胡同百年卤煮（24小时营业），猪肠、肺头、豆腐、火烧同煮，人均约40元。
* **豆汁+焦圈**：护国寺小吃（西四店），老北京标配早餐，人均约10元。初尝者需有心理准备。
* **宫廷小吃**：豌豆黄、驴打滚、艾窝窝，护国寺小吃店有售，人均约30元。

## 4. 住宿区域建议

* **前门/崇文门**：步行可达天安门、故宫，交通最便利。酒店价格约200-500元/晚，适合首次来京游客。
* **南锣鼓巷/后海**：胡同四合院体验，老北京风情浓厚。客栈价格约400-600元/晚，适合追求地道体验的游客。
* **王府井/东单**：商业中心，吃饭购物方便。酒店价格约300-1200元/晚，选择范围广。
* **西单/宣武门**：性价比高，地铁1/2号线交汇。酒店价格约200-400元/晚，适合预算有限游客。
* **三里屯/国贸**：夜生活丰富，潮流品牌汇集，高端选择。酒店价格约800-2000元/晚。

## 5. 经典三日行程参考 (Agent 提取样本)

* **第一天：中轴线皇城经典**
  * 上午：清晨天安门广场看升旗仪式，故宫博物院沿中轴线深度游览（约4小时）。
  * 中午：四季民福烤鸭（故宫店）或故宫冰窖餐厅。
  * 下午：景山公园（仅2元）万春亭俯瞰故宫全景，什刹海胡同三轮车游（约100元/小时）。
  * 晚上：南锣鼓巷逛吃，姚记炒肝品地道小吃，后海酒吧街听民谣。
* **第二天：皇家园林与现代北京**
  * 上午：颐和园深度游（北宫门进→佛香阁→长廊→昆明湖→十七孔桥）。
  * 中午：园内听鹂馆宫廷菜（人均120元）或附近小吊梨汤。
  * 下午：圆明园遗址公园（25元，含西洋楼景区）看大水法遗址。
  * 晚上：奥林匹克公园看鸟巢和水立方夜景，三里屯太古里晚餐。
* **第三天：文化深度与胡同烟火**
  * 上午：天坛公园看祈年殿和大爷晨练（南门进），雍和宫请香灰琉璃手串。
  * 中午：五道营胡同藏红花餐厅或元古本店甜品。
  * 下午：前门大街/大栅栏逛内联升布鞋和张一元茶庄，杨梅竹斜街模范书局打卡。
  * 返程前：稻香村买伴手礼（认准"三禾"标志），前门大街店支持现场快递。
