# 2026 广州深度游玩全攻略

## 1. 目的地简介
广州是广东省省会，别称"羊城""花城"，拥有两千多年的建城历史。这里是岭南文化的中心、中国南大门的商贸枢纽，更是闻名遐迩的"美食之都"。从上下九的西关骑楼到珠江新城的花城广场，从沙面岛的欧陆风情到永庆坊的岭南新韵，广州完美融合了老城烟火与现代繁华。全年温暖，10-12月是最佳旅行季节，天气凉爽舒适。

## 2. 核心景点推荐 (含门票与位置信息)

### 2.1 广州塔（小蛮腰）
* **位置**：海珠区阅江西路222号
* **门票**：150元（433米白云星空观光层），摩天轮套票298元
* **游玩时长**：1-1.5小时
* **简介**：广州地标建筑，总高600米。433米观光层可360度俯瞰广州全景。建议选天气好的时段登塔，花城广场和珠江边是拍摄小蛮腰的最佳位置。

### 2.2 沙面岛
* **位置**：荔湾区沙面南街3号
* **门票**：免费
* **游玩时长**：1-1.5小时
* **简介**：珠江冲积而成的沙洲岛，岛上遍布19世纪末的欧陆建筑群，包括领事馆、教堂和洋行。绿树成荫、安静出片，适合悠闲散步和拍照。

### 2.3 陈家祠
* **位置**：荔湾区中山七路恩龙里34号
* **门票**：10元
* **游玩时长**：1-1.5小时
* **简介**：岭南建筑艺术的集大成者，以精美的砖雕、石雕、木雕和灰塑闻名，被誉为"岭南建筑艺术的明珠"。是了解广府文化的必到之处。

### 2.4 永庆坊
* **位置**：荔湾区恩宁路99号
* **门票**：免费
* **游玩时长**：1-2小时
* **简介**：由老西关街区改造而成的文创地标，保留了趟栊门、青砖墙等岭南建筑元素。内设李小龙祖居、粤剧艺术博物馆和各类文创小店，是体验"老城市新活力"的最佳去处。

### 2.5 石室圣心大教堂
* **位置**：越秀区一德路旧部前56号
* **门票**：免费（周一闭馆）
* **游玩时长**：30-45分钟
* **简介**：全球四座全石结构哥特式教堂之一，有"远东巴黎圣母院"之称。彩色玻璃窗在阳光下光影璀璨，建议白天前往拍摄。

### 2.6 越秀公园
* **位置**：越秀区解放北路988号
* **门票**：免费
* **游玩时长**：1-1.5小时
* **简介**：广州最大的综合性公园，园内有广州城市标志——五羊石像，以及镇海楼、明代城墙遗址等古迹。清晨可看到本地人晨练的市井画面。

## 3. 特色餐饮与预算参考

* **早茶**：广州饮食文化的精髓。陶陶居虾饺皇和酥皮水牛奶菠萝包为人均80元；点都德红米肠是经典必点；泮溪酒家（荔枝湾畔，米其林推荐）人均40-80元。
* **煲仔饭与啫啫煲**：惠食佳啫啫黄鳝煲为人均90元；吴财记云吞面（60年老字号）人均20元。
* **肠粉**：银记肠粉鲜虾肠粉为广州肠粉代表，人均约20元。
* **甜品**：南信牛奶甜品双皮奶和姜撞奶为百年来打卡必点，人均约25元。百花甜品凤凰奶糊人均约15元。
* **凉拌鱼皮**：陈添记（宝华路）凉拌鱼皮爽脆开胃，约35元/份。
* **椰子炖品**：达杨原味炖品椰子竹丝鸡清甜滋补，约20元/盅。
* **老火靓汤与葱油鸡**：向群饭店为本地人家庭聚餐首选，人均约70元。

## 4. 住宿区域建议

* **北京路/公园前**：景点集中，步行可达多处，美食丰富。酒店价格约300-900元/晚，适合首次来穗游客。
* **珠江新城/天河**：现代化中心，夜景好，交通枢纽。酒店价格约600-2500元/晚，适合商务出行和购物达人。
* **上下九/荔湾**：西关老城区，深度文化体验。酒店价格约300-500元/晚，适合老城文化爱好者。
* **海珠广场/江南西**：性价比高，商圈多，近珠江。酒店价格约200-400元/晚，适合预算有限游客。

## 5. 经典三日行程参考 (Agent 提取样本)

* **第一天：老城文化之旅**
  * 上午：沙面岛欧陆建筑群漫步拍照，石室圣心大教堂欣赏哥特式建筑。
  * 中午：宝华路/上下九——陈添记鱼皮（35元）和南信双皮奶（20元）。
  * 下午：永庆坊逛文创小店和李小龙祖居，陈家祠（10元）看岭南建筑精华。
  * 晚上：北京路步行街看千年古道遗址，大佛寺夜景出片。
* **第二天：现代都市体验**
  * 上午：广州塔（150元）433米高空俯瞰全城。
  * 中午：花城广场拍广州塔最佳全景机位，附近商场就餐。
  * 下午：广东省博物馆（免费需提前3天预约，周一闭馆）看历史文化展。
  * 晚上：珠江夜游（78元起，天字码头登船），看两岸灯光秀。
* **第三天：自然休闲之旅**
  * 上午：越秀公园看五羊石像和镇海楼，中山纪念堂外观打卡。
  * 中午：西华路美食街——食盈碗仔翅（20元）和荔林食店。
  * 下午：东山口民国别墅群文艺漫步，或白云山（5元）登高远眺。
  * 晚上：太古仓或琶醍看日落江景，晚餐后返程。
